🌦️ Weather Forecast & Alert Application

A Flutter-based weather application that provides real-time weather information, multi-day forecasts, temperature visualization, and configurable weather alerts based on the user's location or a searched city.

The application is designed with a responsive interface and is deployed as a Flutter Web application using GitHub Pages, with automated deployment through GitHub Actions.

📌 Project Overview

The Weather Forecast & Alert Application provides users with weather information based on their current location or a selected city.

The application integrates the OpenWeather API for weather data and Firebase for cloud-based application services.

It also allows users to configure weather alert thresholds and maintain their preferences across sessions.

✨ Features

🌍 Current Location Weather
